MultiValue Basic Utility (MVBU)

Privacy Policy

Effective date: 5 November 2026

Applies to the MVBU extension for Google Chrome and Microsoft Edge, version 0.3.1, published by Clarity Ascend.

In short: Clarity Ascend collects no data from you. MVBU has no analytics, no tracking and no cloud service. Your settings, history and passwords stay on your own computer. Your database content goes only between your computer and your own database server.

What MVBU does

MVBU shows UniVerse and UniData (Rocket MultiValue database) data in your browser. It shows command output, records, file dictionaries and the results of API calls (catalogued subroutines).

MVBU is read-only by design. It does not edit records. You can type any TCL/ECL command you choose in the Developer console. Those commands run with your own database permissions.

How it works

The extension talks only to a small helper program on the same computer. The helper is written in Python and uses Rocket's uopy library. The extension and the helper talk through Chrome native messaging, using the host name com.clarityascend.mvbu.

The helper connects directly to the database server that you configure. It uses UniRPC (default port 31438). SSL is on by default.

There is no Clarity Ascend server, gateway or cloud service in between.

Data Clarity Ascend collects

None.

  • No analytics or telemetry.
  • No crash reports.
  • No ads and no tracking.
  • The extension makes no network requests of its own.
  • The extension loads no remote code. It uses Manifest V3 and all its code is bundled in the package.

Data stored on your computer

MVBU stores the following on your computer only. None of it is sent to Clarity Ascend.

Connection profiles

Name, database type, host, port, service, account, user name, SSL, flavor and options. These are kept in the browser's extension storage (chrome.storage.local).

Passwords

The helper saves passwords in your operating system's password store. That is macOS Keychain, Windows Credential Manager, or the store used by the Python keyring package.

If no system password store is available, the password is kept in the browser's extension storage on that computer. The extension shows a notice when this happens.

Passwords are never written into the profile settings.

History, favourites and settings

Command history, favourites, saved API call definitions, settings and saved output (Markdown copies of results) are kept in the browser's extension storage. You can download output as .md or .zip files. You can clear history at any time.

Logs

The helper may write log lines to the extension's log view. Logs stay on your computer.

Your database content

Records and command output come from your own database server. They stay on your computer unless you copy, download or share them yourself.

Permissions and why MVBU needs them

PermissionWhy
nativeMessagingTo talk to the local helper program.
storageTo keep profiles, history, settings and saved output on your computer.
unlimitedStorageSaved output and history can be large.
clipboardWriteFor the Copy button on results.

MVBU has no host permissions. It cannot see or access the web pages you visit.

Sharing and selling

Clarity Ascend does not receive your data. So we do not sell, transfer or share it.

Your data is not used for any purpose unrelated to the extension's single purpose. It is not used to decide creditworthiness or for lending.

Limited Use

MVBU follows the Chrome Web Store User Data Policy, including its Limited Use requirements. In plain words:

  • Data is used only to provide the extension's single purpose: showing your MultiValue database content in your browser.
  • Data is not transferred to anyone.
  • Data is not used for advertising.
  • Data is not read by humans at Clarity Ascend.

Removing your data

  • Uninstall the extension. This removes its browser storage.
  • Delete saved passwords from your system password store. Look for entries under the service name MVBU.
  • Remove the helper registration and files that the install scripts created:
SystemLocations
Windows Registry key HKCU\Software\Google\Chrome\NativeMessagingHosts\com.clarityascend.mvbu and the Edge, Chromium and Brave equivalents. The folder %LOCALAPPDATA%\MVBU\.
macOS ~/.mvbu/ and ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.clarityascend.mvbu.json
Linux ~/.mvbu/ and ~/.config/google-chrome/NativeMessagingHosts/com.clarityascend.mvbu.json

Third parties

  • Your database server. MVBU connects only to the server you configure.
  • Rocket Software's uopy library. It runs locally on your computer, inside the helper.
  • Chrome Web Store and Microsoft Edge Add-ons. These stores have their own privacy policies for installs.

Children

MVBU is not directed at children.

Changes to this policy

We may update this policy. When we do, the effective date at the top will change. The extension's store listing links to the latest version.
